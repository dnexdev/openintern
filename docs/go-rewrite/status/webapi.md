## Ready APIs

The site integration signature remains:

```go
site.Register(mux *http.ServeMux, store *board.Store)
```

Construct a store with:

```go
func board.NewStore(opts board.Options) *board.Store
```

`Options.DumpSource` accepts an HTTP(S) URL, a `file://` URL, or a local path. Empty values use `JOBS_DUMP_URL` and the production release URL. `Options.HealthSource` and `Options.KillSwitchSource` have equivalent overrides; clock, HTTP client, refresh intervals, registry callbacks, and the public-job predicate are injectable for tests.

The compiled read surface is:

```go
func (s *Store) Query(context.Context, board.FamilyQuery) (board.FamilyPage, error)
func (s *Store) Job(context.Context, string) (*board.JobDetail, board.DataSource, error)
func (s *Store) JobByCompanyAndIDPrefix(context.Context, string, string) (*board.JobDetail, board.DataSource, error)
func (s *Store) Company(context.Context, string) (*board.Company, board.DataSource, error)
func (s *Store) Companies(context.Context, bool) ([]board.Company, board.DataSource, error)
func (s *Store) CompanyOptions(context.Context) ([]board.CompanyOption, board.DataSource, error)
func (s *Store) CorpusStats(context.Context) (board.CorpusStats, error)
func (s *Store) HeroPreview(context.Context) (board.HeroPreview, error)
func (s *Store) HealthSnapshot(context.Context) (*board.HealthSnapshot, error)
func (s *Store) DumpStatus(context.Context) (board.DumpStatus, error)
func (s *Store) StaleData(context.Context) board.StaleState
func (s *Store) SitemapEntries(context.Context, int) ([]board.SitemapEntry, error)
func (s *Store) RefreshKillSwitch(context.Context) board.KillSwitch
func (s *Store) CanonicalCompanySlug(string) string
func (s *Store) JobAlias(string) string
func (s *Store) JobAliasByPrefix(string) string
```

`board.StoreReader` contains the page/API read methods for fakes.

## Parity evidence

- `go test ./internal/board ./internal/web ./cmd/openintern` and `go vet ./internal/board/... ./internal/web/... ./cmd/openintern` pass.
- Six byte-identical JSON goldens cover the default and combined-filter job lists, a pagination edge, one job detail, companies derived from an older dump, and degraded health.
- Live server comparison used the same 1,434-job public dump through the TypeScript server on port 3201 and Go on port 8201. Of 86 requests, 85 had byte-identical JSON bodies, matching status codes, content types, cache headers, rate-limit remaining headers, and data-source headers. The matrix covered every role, region, term, supported board duration, comma/repeated filters, text search, combined filters, all sorts, `posted_after`, invalid and clamped page/limit inputs, last/empty pages, unknown companies, 17 job IDs including uppercase and unknown IDs, all company variants, degraded health, and stale status.
- The sole current mismatch is an old company-slug filter. The TypeScript server canonicalizes it through registry aliases; the Go server will match after `internal/registry` lands.

## Divergences

- After a successful initial load, failed dump and health refreshes keep serving the last good copy. This is the rewrite requirement and avoids an outage during a transient release-host failure.
