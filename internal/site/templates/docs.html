API & dumps

OpenIntern is a free, structured corpus of tech internships. Browse the board with no account. Mark applied status in your browser only. Query the public API or download the daily dump for bulk use.

Endpoints

GET /api/v1/jobs query parameters

ParameterNotes
qTitle substring, case-insensitive
companyCompany slug, exact
rolesoftware|backend|frontend|fullstack|data|ml|mobile|security|devops|hardware|quant|product|research. Repeatable or comma-separated; values are OR-ed.
regionremote|us|canada|europe|other. Repeatable or comma-separated; values are OR-ed.
seasonsummer|fall|winter|spring. spring is its own season since 2026-10-24; before, it was folded into summer. Repeatable or comma-separated. Board-compatible alias: term.
duration_monthsRepeatable or comma-separated integers (1 to 24). Matches jobs whose duration overlaps any selected value, so Cohere’s “4–6 months” matches 4 or 6. Board-compatible alias: duration.
posted_afterISO date; jobs posted on or after it
pagePage number, default 1
limitPage size in role families, default 27, max 100

The live API is grouped by role family: the same title across locations is one entry. The response is { jobs, page, limit, total, total_pages, has_more }. Each entry has role_family_id, company, title and postings[] with id, title, location, posted_at and apply_url. Daily dumps stay flat, one row per posting.

Examples

curl "https://openintern.dev/api/v1/jobs?role=ml,software&limit=10"
curl "https://openintern.dev/api/v1/jobs?region=canada&season=fall,winter"
curl "https://openintern.dev/api/v1/jobs?duration_months=4,6"
curl "https://openintern.dev/api/v1/jobs/{id}"
curl "https://openintern.dev/api/v1/companies"
curl "https://openintern.dev/api/v1/health"

Rate limits and bulk access

The hosted API allows 60 requests per minute per IP by default and reports what is left in X-RateLimit-Remaining. Limits are best-effort on serverless instances and may change for stability. For bulk use, take the daily dumps below or self-host rather than paging through the hosted API all day.

Daily dumps

Stable download URLs, refreshed every day by GitHub Actions under the release tag dump-latest:

FileContents
jobs.jsonEvery public job, in the envelope { generatedAt, count, jobs }
jobs.csvThe same rows, flat. Both also ship gzipped as jobs.json.gz and jobs.csv.gz
companies.jsonThe company registry
health.jsonThe pipeline snapshot behind Health
LICENSE-DATA.txtTerms for the data, including what mirrors must do
denylist.jsonJob ids taken down by request; mirrors must drop them
MANIFEST.jsonCounts, plus the size and SHA-256 of every file

Dump fields

JSON and CSV rows include id, title, company, company_slug, locations, apply_url, excerpt, terms, term_years, duration_months (integers), cohort_year, roles, regions, is_remote, source, posted_at, first_seen_at, last_seen_at, and since November 2026 role_family_id and normalized_title.

Seasons are summer|fall|winter|spring. A listing with a season stays up until the day before that season starts. Past seasons and old postings without term years are hidden the same way on the board, the API, the sitemap, job pages and the dumps.

Add a company

Extend the corpus with a YAML pull request; see CONTRIBUTING.md. Public boards on Greenhouse, Lever, Ashby, Workable, SmartRecruiters, Recruitee, Rippling, BambooHR and Workday need only a board token; Phenom, Avature, iCIMS, Eightfold and a few named careers sites have their own adapters.
